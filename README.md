One 1024×1024 newspaper front page that sums up Sunday 22 November 2026's world news in 30 dated stories: COP31 collapses with no deal, 186 drones over Ukraine overnight, and sea drones strike a Russian warship at Benghazi — plus a world map with numbered pins, a UTC timeline and a date check. Every story is drawn in code by build.py; main.ts copies the rendered image to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
